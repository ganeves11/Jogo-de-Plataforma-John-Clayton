# Jogo de Plataforma 2D - John Clayton

Projeto de desenvolvimento de jogo de plataforma 2D realizado para aplicação de conceitos de Programação Orientada a Objetos (POO) e lógica de software através da Godot Engine.

## Demonstração
A versão estável do projeto pode ser executada via navegador através do link abaixo:
[Link para o projeto no Itch.io](https://ganeves.itch.io/godot-john-clayton-ama-sanduches)

## Especificações Técnicas
* **Motor Gráfico:** Godot 3.5.3.
* **Linguagem:** GDScript (Sintaxe baseada em Python 3.5.3)
* **Versionamento:** Git
* **Ambiente de Deploy:** Itch.io (HTML5)

## Implementações Realizadas
* **Estrutura de Código:** Organização modular de scripts para controle de personagens, inimigos e interface de usuário (UI).
* **Física:** Desenvolvimento de sistemas de gravidade, aceleração e detecção de colisões via KinematicBody2D.
* **Comunicação entre Objetos:** Utilização de Sinais (Signals) para garantir o baixo acoplamento entre os componentes do jogo.
* **Gerenciamento de Recursos:** Estruturação de diretórios para Assets, Scenes e Scripts.
